# App-Icon, Entwurf 2

Mit dem integrierten Imagegen-Werkzeug generiert; als macOS-AppIcon in allen erforderlichen Größen eingebunden. Aktuelle Quelle: `AppIcon-source-v2.png`. Der erste Entwurf `AppIcon-source.png` bleibt zum Vergleich erhalten. `scripts/build-icon.sh` erzeugt die Größen des Asset-Katalogs mit sips und erhält die Transparenz. Das Raster-Icon ist ein eigenständiger Entwurf; separate Icon-Composer-Ebenen und Erscheinungsvarianten sind ein späterer Designschritt.

Finaler Prompt für den eingebundenen Entwurf 2:

> Create a fresh original native macOS app icon for a screenshot editor named SnagForge. 1024x1024. No text. Very simple graphic: one cobalt-blue rounded square tile centered with a small TRANSPARENT margin around it, white screenshot-frame corner brackets and a thick coral orange arrow pointing diagonally up and right. Modern refined glass-like material INSIDE THE TILE ONLY, strong simple shapes readable at 16px. The outer tile silhouette must be perfectly crisp and smooth with NO drop shadow, NO bloom, NO outer glow, NO haze, NO particles, NO texture outside its perimeter. Outside the single rounded square tile use completely empty transparent alpha. No luminous edge bleeding onto the transparent margin. Precise clean icon asset, restrained 2.5D appearance, orthographic front view. Avoid photorealistic reflections or dramatic glossy lighting. The tile is self-contained and its entire contour is clean, like a carefully drawn app icon.

Prompt des ersten Entwurfs:

> Use case: logo-brand. Asset type: production macOS app icon, 1024x1024 square image. Create one original icon for a native Apple screenshot and annotation application, working name SnagForge. No lettering anywhere. A single softly rounded square cobalt-blue to indigo glass tile, straight-on orthographic view, centered occupying 86% of the canvas. On the tile, four substantial luminous white capture-frame corner brackets surround a single bold coral orange annotation arrow pointing up-right. Only those two simple shapes, balanced, generous spacing, extremely legible at 32 pixels. Contemporary restrained macOS Liquid Glass material: subtle bevel, controlled upper-left specular light, dimensional translucent edges, high contrast, carefully crafted. The arrow should feel like a graphic editing mark, not a mouse cursor. No camera lens, no sparkles, no text, no badge, no extra icons, no mockup, no desktop scene. Background outside the single tile must be genuinely transparent, retaining alpha. Finished standalone icon asset.
